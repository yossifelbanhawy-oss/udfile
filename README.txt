udfile - Simple Download Website

1. Extract this ZIP file.
2. Put your downloadable files inside the files folder.
3. Open script.js and edit the files array:
   name: "YourFile.zip"
   url: "files/YourFile.zip"
4. Save and open index.html in your browser.

The sample names Game.zip, Manual.pdf and Program.exe are examples.
Replace them with files that actually exist in the files folder.

To let other people access the website, upload the project folder to a web host.
